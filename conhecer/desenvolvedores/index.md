# Desenvolvedores

Esta seção é voltada a quem integra sistemas externos à Anexus via **API REST**. **Conhecer** explica a teoria do produto; **Referência** reúne conteúdo técnico interno e de contribuição.

A **API da Anexus** permite consultar contratos, enviar documentos, acompanhar status e automatizar fluxos que hoje são feitos manualmente na área interna.

## O que a API oferece

| Área | Exemplos |
|------|----------|
| **Autenticação** | Chaves de API para acesso programático |
| **Contratos** | Listagem, detalhes e operações sobre pedidos |
| **Portal** | Consulta de status e documentos do dossiê |

A especificação OpenAPI está disponível em ambiente de desenvolvimento (`/openapi/v1.json`). A referência publicada na documentação ainda está em construção — veja [Status de implementação](/referencia/status-implementacao).
