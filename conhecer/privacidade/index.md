# Privacidade de Dados

A Anexus é a **plataforma** de serviços documentais e, para isso, trata **dados pessoais** de contratantes, beneficiários e usuários autenticados — nomes, documentos, e-mails, endereços IP no aceite, anexos do dossiê e demais informações necessárias ao serviço.

Esta seção reúne o que você precisa saber sobre proteção de dados na plataforma: o que a lei exige, quem faz o quê no tratamento, **como os dados são usados**, o **ciclo de vida** até a anonimização, quais são os direitos do titular e como exercê-los.

## O que a plataforma trata

| Contexto | Exemplos |
|----------|----------|
| **Contrato e pedido** | Identificação das partes e descrição do serviço |
| **Aceite e dossiê** | Registro no portal e documentos do caso |
| **Conta de usuário** | Dados de cadastro do operador ou do login de convite |

Detalhes das finalidades: [Como meus dados são usados](/privacidade/uso-dos-dados). O tratamento deve seguir a [Lei Geral de Proteção de Dados (LGPD)](https://www.planalto.gov.br/ccivil_03/_ato2015-2018/2018/lei/l13709.htm).
