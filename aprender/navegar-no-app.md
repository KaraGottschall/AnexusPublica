1. Use **Início** na barra lateral esquerda para voltar à página inicial. Em telas estreitas, a barra vira um overlay; em tablet ela pode ficar só com ícones.
2. Abra o menu do usuário no rodapé da barra lateral para acessar **Perfil** e **Configurações**.
3. No mesmo menu, escolha **Aparência**: Claro, Escuro ou Sistema.
4. Use **Aprender** ou **Conhecer** no menu do usuário para abrir tutoriais ou a teoria do produto.
5. Para sair, clique em **Sair** no menu do usuário.
